## 0. 结论摘要

1. **完整 chat 循环实测通过**：prompt「中国的首都是」(n=3) + **24 步 decode**，两套配置（ION fp16 centroid / DDR fp32+mlock）均完整跑完，**bit-exact 0 项（bad1=bad2=r_opt=rsh=0）**。
2. **decode 精确数据**：ION 路径 **avg 10.85s/token**（t_layers 10.31 + t_head 0.55），DDR 路径 **avg 11.13s/token**（SD 热漂移，非路径差异）。逐 token 表见 §2。
3. **FFN 主导 decode compute**：per-matmul 墙钟 FFN（up+gate+down）= **8.20s/token（83.8%）**，Attention（q+k+v+wo）= 1.59s/token（16.2%）。其中 CPU INT4→INT8 dequant 占 matmul 墙钟 58%（5.70s/token）。
4. **SD 权重读取**：层权重 mmap 每步 majflt ≈1560、VmSwap 620→1692kB；层权重 ~201MB @21.5MB/s 地板 ~9.37s，与 compute 重叠 → t_layers 10.31s 即 max(SD, compute)+损耗。
5. **EOS 行为**：25 token 生成流（prefill next+24）两路径逐位一致，**24 步内模型未发 EOS（151645）**，进入选择题格式重复循环；引擎按设计跑满 DECODE_STEPS（不因 EOS 提前停），EOS 由 host 侧剥离。

## 3. 分解：SD 权重读取 / LM head / FFN（PROFILE per-matmul，24 步汇总）

### 3.1 matmul 墙钟分解（eng_matmul, 6336 calls / 234.97s）

| 项 | 24 步合计 | per-token | 占比 |
|---|---|---|---|
| **FFN** up+gate+down | 196.83s | **8.20s** | **83.8%** |
| ├─ up | 58.02s | 2.42s | 576 calls × 100.7ms |
| ├─ gate | 68.55s | 2.86s | 576 calls × 119.0ms |
| └─ down | 70.26s | 2.93s | 2880 calls × 24.4ms |
| **Attention** q+k+v+wo | 38.14s | **1.59s** | 16.2% |
| ├─ q | 15.35s | 0.64s | 576 × 26.6ms |
| ├─ k | 5.89s | 0.25s | 576 × 10.2ms |
| ├─ v | 6.10s | 0.25s | 576 × 10.6ms |
| └─ wo | 10.80s | 0.45s | 576 × 18.8ms |
| **matmul wall 合计** | 234.97s | **9.79s** | 100% |

### 3.2 matmul 内部阶段分解（per-token）

| 阶段 | 合计 | per-token | 占比 |
|---|---|---|---|
| dequant_rvv（CPU INT4→INT8） | 136.78s | **5.70s** | 58.2% |
| runcmdbuf（TIU g2l+matmul+l2g） | 66.24s | **2.76s** | 28.2% |
| invld（l2g DMA） | 7.59s | 0.32s | 3.2% |
| flush（g2l DMA） | 3.54s | 0.15s | 1.5% |
| copy_act | 0.81s | 0.03s | 0.3% |
| blockmax/accum/final | 17.23s | 0.72s | 7.3% |

→ decode compute 瓶颈是 **CPU 端 INT4 dequant（5.70s）+ TIU 提交（2.76s）**，非 TIU 纯算。

### 3.3 SD 权重读取（LW_READ=mmap，与 compute 重叠）

| 项 | 值 | 说明 |
|---|---|---|
| 层权重 | ~201MB（24 × 8.39MB） | @21.5MB/s ≈ 9.37s 地板 |
| 每步 majflt | ~1560 | mmap 页缺失数（SD 读入） |
| VmSwap | 620→1692kB | 匿名 swap 低，无换页抖动 |
| t_layers | 10.31s avg | = max(SD 9.37, matmul 9.79) + ~0.5s 非 matmul 开销 |
| LM head Stage2 span | ~6.0MB/token | pread 128 个连续 span，实测 0.52s（散读，非 21.5MB/s 满速） |

→ SD 读与 compute 基本完全重叠，decode 处于 **compute-bound（9.79s）略高于 SD 地板（9.37s）**。

## 4. EOS 行为

- 生成流（25 token，两路径逐位一致）：
  `2130 198 32 13 220 102012 198 33 13 220 104803 198 34 13 94305 245 73038 198 35 13 220 104803 198 102349 1447`
- **未出现 EOS（151645 `<|im_end|>`）或 pad（151643）**：模型对「中国的首都是」接了选择题格式，进入重复循环（见下），24 步内未自然终止。
- 解码文本：`____\nA. 重庆\nB. 陕西\nC. 北宋\nD. 陕西\n答案:\n\n`
- **引擎行为**：decode 固定跑满 `DECODE_STEPS`（本测 24 步），**不因 EOS 提前停止**——设计如此，EOS 剥离在 host 侧（chat_qwen.py `strip_special_ids`）。KV_CAP=48 实际给 45 个 decode 槽（prompt 3），本次未触顶。
- 两路径（ION/DDR）生成流逐位一致 → **centroid 放置不影响 decode 正确性**。

## 5. ION vs DDR A/B（同为 24 步完整跑完）

| 指标 | ION fp16（run2） | DDR fp32+mlock（run3） |
|---|---|---|
| total avg | **10.853s** | 11.128s |
| t_layers avg | 10.306s | 10.569s |
| t_head avg | 0.548s（s1 0.024） | 0.560s（s1 0.010） |
| s1（stage1 dot） | 0.024s（f16→f32 逐元素） | 0.010s（预转 fp32） |
| s2（stage2 span） | 0.523s | 0.550s |
| matmul wall | 234.97s | 240.49s |
| VmSwap avg | 1229kB | 1811kB |
| majflt avg | 1562 | 1619 |
| 生成流 | 25 token 与 DDR 逐位一致 | 与 ION 逐位一致 |
| bit-exact | 0 项 | 0 项 |

→ ION 路径 stage1 因逐元素 f16→f32 比 DDR 预转 **+14ms/token**（与落地报告一致），但总延迟反而略低（SD 漂移，run3 后跑更热）；两路径正确性一致，**ION 路径更省匿名内存（VmSwap -580kB）**。
