# 最新部署成果（中文版）— 2026-10-17

> English version: `STATUS_20261017_en.md`

## 1. 当前已部署模型

板上（Milk-V Duo 64M，CV1800B）当前部署并可运行两个模型：

| 模型 | 形态 | 上下文 | Decode | 状态 |
|---|---|---|---|---|
| **Qwen2.5-0.5B-Instruct**（主力） | INT4 G32 K-aligned 权重 + INT8 per-token KV | 192 tok | **~11.1 s/token** | 出货配置 `mmap + GSC_ION=1`，板上二进制 `qwen_engine_lmhead2_b2` |
| **SmolLM2-135M-Instruct** | INT8 权重 + INT8 KV | 156 tok | ~4.9 s/token | 早期交付，稳定可运行 |

Qwen 权重位于 SD 卡 `/data/qwen`，约 324 MB（embed 136 MB + 24 层 × 约 8.1 MB）。
模型结构：24 层、hidden 896、14 heads / 2 KV heads、head_dim 64、FFN 4864、vocab 151,936。

## 2. Qwen 最新关键成果（Phase 6 → B2）

- **B2 dequant 已合入 master 并出货**：INT4 nibble `nib[N][16] → nib16[16][N]` 重排 +
  连续 `vle8` RVV 内核。单调用吞吐 **1.75×（N=896）/ 2.02×（N=4864）**；
  端到端 CHAT 75-token prefill **304.5s → 219.6s（↓28%）**，
  decode **16.25 → 10.98 s/token（↓32%）**。
- **两段式 LM head 落地**：1.84 MB centroid fp16 常驻 ION（自适应放置，余量不足回退 DDR）
  + Stage2 span pread；head 成本 0.5–0.7 s，host recall@1 复现 11/11。
- **INT8 KV cache**：上下文 48 → 192（×4），同内存预算，bit-exact。
- **ION 看门狗**：覆盖 init 窗口 + 原子心跳；挂死时 ≤ 超时强制 `_exit(1)`，
  ION 归零无泄漏，正常路径零误杀。
- **正确性基线**：3-prompt NEXT 3/3（2130 / 12095 / 99366）、decode 链 2130→198→32、
  CHAT 75-token 链逐 token 一致，TIU bit-exact 四项全 0。
- **B-P0 权重预取关闭**：本内核 `madvise` / `posix_fadvise(DONTNEED)` 均返回 ENOSYS，
  无释放机制导致预取窗口击穿，全扫测负收益（+2.4~+5.0 s/token）；已归档，转 B-P1。

## 3. 性能与硬件边界

| 指标 | 数值 |
|---|---|
| Decode | 11.10–11.19 s/token（24 层，SD-bound） |
| CHAT prefill，35 tok | 101.7 s |
| CHAT prefill，75 tok | 219.6 s |
| LM head | 0.5–0.7 s |
| Dequant 吞吐 | 538 MB/s（N=896）、753 MB/s（N=4864） |

硬件约束：SD 顺序读 ~20.2 MiB/s、ION carveout 28.1 MB、每 token 权重流量 ~201 MB。
对应 decode 理论地板约 9.45 s；**11.1 s/token 已接近该约束下的工程极限**。

## 4. 运行方式

```sh
cd /data/qwen
# decode 回归（mmap + GSC_ION=1 为引擎默认）
VERIFY=0 RSH=1 DECODE=1 DECODE_STEPS=6 PROFILE=1 ./qwen_engine_lmhead2_b2

# 主机侧对话
experiments/qwen_int4/.venv/bin/python3 chat_qwen.py "你好"
```

## 5. 结论

Qwen2.5-0.5B-Instruct 已在 CV1800B 上完成完整部署：INT4 权重 + INT8 KV + 两段式 LM head，
支持 192 token 上下文与交互式中文对话，正确性 bit-exact，具备看门狗兜底。
后续优化空间主要受 SD 带宽与 ION 容量限制，B-P1（独立线程 pread 双缓冲）为下一步验证方向。
