## 0. 一句话结论

**25.3MB（25,300,992 B）是 ION carveout debugfs 的 boot 累计高水位（跨进程/跨运行不清零），来自 A' 整层 smoke 会话中先前运行（GSC_ION=1 出货基线 ~24.3MB + ~1MB 历史残留/进程叠加），不是 B-2 稳态或 B-2 运行瞬态；B-2 自身实测稳态 26,927,104 B（init）/ ~26.1MB（decode 释放 ps5/7 后），完整跑完 decode 未 OOM。**

## 1. 关键证据（为什么能判定"非本运行瞬态"）

| # | 证据 | 数据 | 结论 |
|---|---|---|---|
| 1 | init 期间 ION 分配**严格单调** | 引擎 L1843→L1977 成功路径：mem→gsc→SD_BUF→pools→mp，**全程无 MemFree** | peak 不可能来自本进程 alloc 再 free |
| 2 | init summary 时点 **peak > used** | `used:26,927,104` / `peak:28,073,984`（aprime_a_perf）；`used:18,759,680` / `peak:25,300,992`（smoke_iondb） | peak 必由**先前进程/配置**在本次运行之前设置 |
| 3 | 首次 B-2 运行 peak == used | b2_perf3.log `used:26,824,704` / `peak:26,824,704`（本会话第一个 B-2 进程） | 干净进程自身**无自增瞬态** |
| 4 | B-2 运行完成不 OOM | aprime_a_perf 跑完 decode（t_layers/total 齐全）时 used 恒 26,927,104 | 26.9MB 稳态在 carveout 内，峰值不阻塞分配 |
| 5 | 设备现态佐证 | 当前会话 `used:0` 但 `peak:28,073,984` 保留 | peak 是历史最高，不与当前占用叠加 |

## 2. 两个峰值的构成与归属

**25,300,992（smoke_iondb 会话，A' 整层 ion_db）**
- 该会话中 A' 整层稳态 = 18,759,680（SD_BUF 16,793,600 + mem 262,144 + pools 1,703,936）。
- 25,300,992 ≈ GSC_ION=1 出货基线（gsc 24 层 22,364,160 + mem 262,144 + pools ~1,705,984 ≈ 24.33MB）＋ ~970KB 历史残留。峰值来自同 boot 会话先前运行（含失败配置/进程叠加），**非 B-2 路径**。

**28,073,984（当前会话，B-2 阶段）**
- B-2 init 稳态 = 26,927,104（gsc 17 层 15,841,280 + 4 大槽 8,716,288 + 小槽 401,408 + mem 262,144 + pools 1,705,984），余 1,175,552（1.12MB）。
- 28,073,984 = 距 carveout 仅 28KB，为 Phase 8 曾尝试超限配置（"4-big + gsc 19"等失败路径）在失败前贴近 carveout 的高水位残留，**非当前 B-2 配置稳态**。

## 3. 对 B-2 稳态余量的影响判定

**判定：可接受，不需改预算，不是硬阻塞。**

- B-2 decode 稳态 = 26,927,104 − ps5/ps7（~0.8MB）≈ **26.09MB**，余量 **~2.0MB**（init 态余 1.12MB）。
- 25.3MB 峰值 **< B-2 init 稳态 26.93MB**，从数值上就不可能与 B-2 稳态叠加；它属于更小的 A'/GSC_ION=1 配置。
- B-2 运行本身实测不产生高于稳态的 ION 瞬态（证据 3/4）。
- 真正的 OOM 风险在**运营序列**（进程叠加/失败配置），不在 B-2 预算。

**放行 B-2 所需运营护栏（不变，强化）**：
1. 每次运行前 `run_clean.sh --clean qwen_engine_lmhead2_aprime`（杜绝 stale 进程叠加）。
2. decode 前释放 ps5/ps7（已实现，省 ~0.8MB）。
3. ION 分配顺序保持 gsc→SD_BUF→pools 大块优先（已实现）。
4. **不得复现超限配置**（gsc ION 层数 + SD 槽数合计 ≤ 当前 17+5 形态；任何"gsc 19+4 大槽"类实验都会贴到 carveout）。
5. 若需 100% 实证，可 reboot（清 peak）后跑 `ion_trace.sh` 逐 2s 采样确认——静态证据已闭合，非必需。

## 4. 结论

Step 0 完成：**峰值 = 测量口径（boot 累计高水位）＋历史/叠加痕迹，非 B-2 稳态风险；B-2 余量按 V1/V2 预算有效（decode ~2MB），可进入 B-2 实现。**
